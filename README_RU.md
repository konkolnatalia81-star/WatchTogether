# WatchTogether

Первая версия сайта для совместного просмотра видео.

## Уже реализовано
- Создание комнаты с уникальным кодом из 6 символов.
- Вход по коду (до 12 участников в одной комнате).
- Текстовый чат в реальном времени.
- Список участников и передача роли владельца, если владелец вышел.
- YouTube-видео по ссылке через официальный YouTube IFrame Player.
- Загрузка видеофайла на сервер (ограничение 500 МБ).
- Управление воспроизведением владельцем: play/pause, перемотка, seek.
- Голосовой чат на WebRTC mesh для небольших комнат.

## Требования
- Node.js 20 или новее.
- Для микрофона на опубликованном сайте нужен HTTPS (локально `localhost` разрешён браузерами).
- Для стабильного голоса между разными сетями может понадобиться TURN-сервер.
- Для большого количества голосовых участников нужен SFU (например, LiveKit/mediasoup). Текущая mesh-схема — прототип для небольших комнат.
- Загрузка хранится на диске сервера. На бесплатных/эфемерных хостингах файлы могут удаляться после перезапуска или redeploy; для постоянного хранения подключить объектное хранилище.
- Комнаты и чат хранятся в памяти сервера и исчезают при его перезапуске.
- В этой версии вставляется ссылка на YouTube. Поиск по YouTube требует отдельного YouTube Data API key.

## Запуск на компьютере
1. Установи Node.js 20+.
2. Распакуй архив и открой папку `watchtogether`.
3. В терминале выполни:
   ```bash
   npm install
   npm start
   ```
4. Открой `http://localhost:3000`.

## Важно для публикации
Нужен Node.js-хостинг, который поддерживает постоянный процесс и WebSocket (например, Render или другой аналог). Не публикуй `.env` и не добавляй секретные ключи в браузерный JavaScript.
Для публичного использования перед запуском добавь ограничения по частоте запросов, модерацию/жалобы, очистку старых файлов, проверку прав на контент и постоянное хранилище. Установи лимит расходов и проверь лимиты диска/трафика у хостинга.

## Структура
- `server.js` — Express + Socket.IO сервер, комнаты, чат, сигнальная часть WebRTC и загрузка файлов.
- `public/index.html` — интерфейс.
- `public/style.css` — оформление.
- `public/app.js` — клиентская логика, плеер, чат и голос.
