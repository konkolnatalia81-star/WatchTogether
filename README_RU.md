# WatchTogether

Приложение для совместного просмотра видео в комнатах: приглашение по коду, чат, синхронизация видео для владельца комнаты и голосовая связь WebRTC.

## Функции
- Комнаты с уникальным кодом из 6 символов; до 12 подключённых участников.
- Вход по коду, текстовый чат и передача роли владельца при его выходе.
- Видео YouTube через официальный YouTube IFrame Player и видеофайлы на сервере (до 500 МБ).
- Владелец управляет воспроизведением, паузой и перемоткой; сервер передаёт состояние всем участникам.
- Голосовая связь WebRTC mesh для небольших комнат.
- Адаптивный интерфейс для мобильных устройств и планшетов.

## Требования и запуск
Требуется Node.js 20 или новее.

```bash
npm install
npm start
```

Открой `http://localhost:3000`. Проверка сервера: `curl http://localhost:3000/api/health`.

## Переменные окружения
- `PORT` — порт HTTP-сервера (по умолчанию `3000`).
- `STUN_URL` — необязательный STUN URL.
- `TURN_URL`, `TURN_USERNAME`, `TURN_CREDENTIAL` — TURN-сервер для соединений WebRTC через NAT/межсетевые экраны. Укажите TURN credentials как секреты хостинга, не коммитьте их в репозиторий.

Для доступа к микрофону в опубликованной версии требуется HTTPS. Без TURN голос может не соединиться между некоторыми сетями. Mesh-схема предназначена только для небольших групп; для масштаба нужен SFU (например LiveKit или mediasoup).

## Ограничения прототипа
Комнаты и сообщения хранятся в памяти и удаляются при перезапуске процесса. Загруженные файлы находятся в `uploads/`; для эфемерного хостинга подключите постоянный диск или объектное хранилище. Для публичного сервиса добавьте rate limiting, модерацию, квоты и проверку загрузок. Локальный `uploads/` не предназначен для масштабирования на несколько серверных экземпляров.

## Структура
- `server.js` — Express, Socket.IO, комнаты, загрузки и WebRTC signaling.
- `public/index.html` — пользовательский интерфейс.
- `public/style.css` — оформление и адаптивность.
- `public/app.js` — комнаты, плеер, синхронизация, чат и голос.
