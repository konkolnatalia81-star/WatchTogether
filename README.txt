# WatchTogether — дополнительный файл

Файл `upgrades.js` добавляет:
- отображение вертикального видео целиком (без обрезки);
- кнопку полноэкранного режима;
- кнопку микрофона поверх плеера;
- обновление значка Play/Pause;
- сохранение кода последней комнаты и попытку повторного входа после обновления;
- локальный список ранее загруженных видео.

## Подключение
1. Положи `upgrades.js` в папку `public` рядом с `app.js`.
2. В `public/index.html` найди строку:
   `<script src="/app.js"></script>`
3. Сразу после неё добавь:
   `<script src="/upgrades.js"></script>`

## Важно
Это дополнительный клиентский файл, а не полная замена проекта. Сохранение библиотеки здесь хранит ссылки в браузере; сами видео остаются на сервере только пока серверное хранилище Render сохраняет файлы. Для надёжного хранения после перезапусков Render нужен Persistent Disk или внешнее хранилище.
